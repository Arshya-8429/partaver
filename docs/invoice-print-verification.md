## Failed / blocked / not tested

- No open source regression remains in this scoped document gate; earlier failed diagnostic runs remain available.
- Native Android/WebView print bridge, actual phone print UI, real printers and manual screen-reader interaction remain untested.
- The final desired company invoice sample has not been supplied. The configurable default template can be replaced later.
- Local documents are not synchronized between devices. Browser clearing/eviction can remove them; retain JSON backups outside browser storage.
- Genuine historical company data was unavailable. Price-history tests use explicit synthetic fixtures in disposable storage; production prices/history were not fabricated.
