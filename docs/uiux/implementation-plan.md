# اجرای بازطراحی PartsFinder — ۲۰۲۶/۱۰/۲۷

درخواست مستقیم کاربر «ظاهر رو درست کن» مجوز اجرای طرح آماده‌شده است. اجرا در همین پروژه، با TypeScript/CSS و بدون وابستگی جدید انجام می‌شود. نسخهٔ قبلی رابط در `reports/uiux/before/production-ui-source-2026-10-27.tar.gz` محفوظ است.

1. آزمون تعامل واقعی: نصب اختیاری، جست‌وجوی آنلاین محدود، انتخاب صریح تیپ، جزئیات و کپی، لغو پاسخ قدیمی، تم و اندازه‌های مختلف.
2. پوسته و توکن‌ها: هدر جمع‌وجور، دو حالت جست‌وجو، کنترل خودرو، کارت‌های فشرده، قیمت‌های کامل و پنجرهٔ جزئیات.
3. اتصال خواندن: استفاده از Worker برای دادهٔ نصب‌شده؛ API موجود برای اولین اجرای آنلاین؛ گروه‌بندی گونه‌ها با صفحهٔ ۱۰تایی و حفظ ترتیب دامنه.
4. وضعیت واقعی: تفکیک اتصال، کاتالوگ و پوستهٔ آفلاین؛ نصب دستی، پیشرفت، لغو و حفظ نسخهٔ فعال.
5. اجرای typecheck/lint/unit/integration/build/bundle/E2E و بررسی منبع/پایگاه؛ ثبت خروجی واقعی.
6. تصاویر پس از اجرا، مرور نهایی با روش‌های UI UX Designer، مستندات و نمایش نسخهٔ اجراشده در 4173.

موارد حساس: متن مبهم خودرو نباید اولین تیپ را انتخاب کند؛ clear/tab پاسخ قدیمی را کنار می‌گذارند؛ بررسی نسخهٔ بدون تغییر انتخاب کاربر را حفظ می‌کند؛ هیچ خانواده‌ای قیمت یا خودروهای مشترک نشان نمی‌دهد؛ قیمت‌ها رشته و هر کد لجستیکی مستقل می‌مانند.

## نتیجهٔ اجرا

هر شش مرحله اجرا شد. شواهد: `docs/uiux/verification-report.md` و `reports/uiux/after/verification-summary.json`. ۱۸ unit، ۲۳ integration و ۸ E2E موفق‌اند؛ تصویرهای واقعی و روش بازبینی پلاگین ثبت شده‌اند. موارد نیازمند دستگاه واقعی و آزمون‌های فشار تکمیلی در `REMAINING-WORK.md` مشخص شده‌اند.
