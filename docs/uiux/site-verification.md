# راستی‌آزمایی وب‌سایت عمومی PartAvar

تاریخ: ۲۷ اکتبر ۲۰۲۶. آزمون‌ها روی build واقعی Vite در Chrome 156 اجرا شده‌اند؛ وب‌سایت معرفی از برنامهٔ عملیاتی `/app/` جداست.

## نتیجهٔ Playwright

پنج آزمون وب‌سایت در اجرای کامل `reports/partavar/final-e2e.log` موفق‌اند:

- شش route محتوای متمایز، title/description/Open Graph، لینک‌های داخلی معتبر و 404 کاربرپسند دارند؛ route عمومی درخواست API کاتالوگ نمی‌فرستد.
- پیمایش صفحه‌کلید، skip link، منوی واکنش‌گرا، Escape و بازگرداندن focus، ورود به برنامه و لینک‌های help آزموده شدند.
- هر route در تم روشن و تیره و عرض‌های 320، 360، 390، 430، 768، 1024 و 1440px بررسی شد؛ overflow افقی و هدف لمسی کوچک‌تر از 43.5px در اجرای تست پیدا نشد. zoom متن 200% نیز بررسی شد.
- تصویر پیش‌نمایش واقعی بارگیری شد؛ پس از قطع عمدی همان asset، fallback و دسترسی به برنامه باقی ماند.
- contact صفحه اطلاعات تماس یا فرم ساختگی نشان نمی‌دهد.

تصاویر واقعی در `reports/partavar/site-home-light-1440.png`, `site-home-dark-1440.png`, `site-home-light-390.png`, `site-home-dark-390.png` و نماهای support ذخیره شده‌اند. کنتراست توکن‌های مشترک به‌صورت ایستا اندازه‌گیری شد: `reports/partavar/site-contrast.json`. این اندازه‌گیری ادعای کنتراست همهٔ ترکیب‌های rendered یا انطباق کامل WCAG نیست.

## بازبینی UX و روش

روش‌های نصب‌شدهٔ UI UX Designer برای audit، طراحی واکنش‌گرا، دسترس‌پذیری و handoff به‌کار رفتند. نسخهٔ حاضر ابزار مستقل MCP/remote طراحی ندارد؛ هیچ اجرای خارجی پلاگین یا خروجی ساختگی به آن نسبت داده نمی‌شود. بازبینی واقعی از مرور صفحات buildشده، تصاویر Chrome، Playwright و lint/typecheck انجام شد.

یافته‌های پیش از اجرا و تصمیم‌ها در `site-proposal.md` و `site-handoff.md` هستند. رابط در دو تم، هدف‌های بزرگ، contact صادقانه و fallback تصویر را حفظ می‌کند. برنامهٔ قطعات بخش مجزای کاری باقی می‌ماند و سایت به صفحهٔ بازاریابی عمومی تبدیل نشده است.

## موارد آزمون‌نشده

- screen reader، فناوری کمکی واقعی و ممیزی رسمی WCAG.
- Safari، Firefox، Android و WebView دستگاه واقعی.
- HTTP 404 واقعی سمت سرور، crawler در مقصد و Core Web Vitals میدانی؛ سایت deploy نشده است.
