# گزارش راستی‌آزمایی بازطراحی PartsFinder

وضعیت: **در رابط اصلی پیاده شده و اجرا شده است.** تاریخ: ۲۷ اکتبر ۲۰۲۶. دستور مستقیم کاربر برای اصلاح ظاهر، مجوز اجرای طرح آماده‌شده بود. پیش‌نمایش قدیمی، محصول نهایی محسوب نشده است.

## چه چیزی پیاده شد

- پوستهٔ فارسی RTL، هدر جمع‌وجور، دو روش جست‌وجو، انتخاب سریع خودروهای واقعی پشت disclosure، تم روشن/تیره با اولویت تنظیم ذخیره‌شده و سپس سیستم.
- لیست فشردهٔ تک‌ستونه با چیدمان متراکم دسکتاپ؛ کد فنی و لجستیکی کامل، LTR و قابل انتخاب/کپی؛ سه قیمت از رشته‌های صحیح دامنه، بدون تغییر محاسبه یا حدس واحد.
- پنجرهٔ lazy جزئیات با focus، Escape، Back و بازگرداندن focus؛ خانوادهٔ خنثی بدون قیمت/خودرو مشترک؛ گونه‌های یکتا و ردیف‌های لجستیکی در صفحات حداکثر ۱۰تایی.
- facade خواندن: Worker برای نسخهٔ نصب‌شده، API موجود برای نخستین اجرای آنلاین؛ صفحهٔ اصلی حداکثر ۲۰ نتیجه؛ هیچ کاتالوگ کامل یا نمایه‌ای به main thread منتقل نمی‌شود.
- نصب دستی و قابل لغو، پیام فارسی مراحل، برآورد فضای ذخیره، بررسی جداگانهٔ پوسته و داده. جست‌وجوی محلی قبل از انتظار شبکه فعال می‌شود. بررسی بدون تغییر، انتخاب خودرو را حفظ می‌کند.
- کش پوسته با شناسهٔ ساخته‌شده از build؛ HTML fallback همان نسخه با فایل‌های خودش نگهداری می‌شود. readiness با کنترل‌کنندهٔ Service Worker و حضور فایل‌های جاری بررسی می‌شود. API و کاتالوگ در cache پوسته نیستند.

## آزمون‌های تعاملی و داده

- انتخاب مبهم `X33 Cross` با Enter بدون active option انتخاب نمی‌شود؛ Arrow/Enter انتخاب صریح CVT می‌کند؛ Escape و بازشدن دوباره با ArrowDown نیز آزموده شد؛ گزینهٔ MT و گزینهٔ دیگر حفظ شده‌اند. انتخاب دقیق با Enter، clear خودرو و preset واقعی بررسی شد.
- هر دو حالت جست‌وجو؛ جست‌وجوی خودروی X33 Cross CVT برای «سپر»؛ کد/نام، query سه‌حرفی `150` با ۱٬۲۷۴ نتیجه و صفحهٔ دوم؛ ارقام فارسی و عربی؛ حالت خالی و ۱۰۰ تغییر سریع بدون انباشت DOM.
- دو قیمت مستقل `111100001AA` و پنج ردیف BA در `0CF25BE-1500011BA` حفظ شدند. قیمت‌های کامل اول این کد: پایه ۳٬۶۴۹٬۶۴۴٬۳۲۱، میانی ۴٬۰۱۴٬۶۰۸٬۷۵۳، نهایی ۴٬۳۷۹٬۵۷۳٬۱۸۵. مدل‌های جزئیات همان ردیف‌اند.
- `112000177AA-03` به‌درستی «اطلاعات خودرو ثبت نشده» نشان می‌دهد؛ این عبارت به معنی سازگاری عمومی نیست. قیمت بزرگ `112000177AA-01` نیز بررسی شد.
- بازکردن/بستن جزئیات، focus روی عنوان و بازگشت روی trigger، Escape و Back، حفظ query و صفحهٔ زیرین؛ خروج به نشانی تازه با dialog باز نیز به history.back ناخواسته منجر نمی‌شود؛ خانوادهٔ بدون قیمت جمعی و بدون رندر فرزندان بسته.
- خانوادهٔ واقعی `019CHA-1502503` با **۱۸ گونه** پس از قطع شبکه در صفحات ۱۰ + ۸ و برگشت به صفحهٔ اول بررسی شد. هیچ کد فنی در منبع بیش از ۸ ردیف لجستیکی ندارد؛ برای آزمودن دکمه‌های بعد/قبل ردیف‌ها، یک آزمون آنلاین صفحهٔ کوچک‌تر واقعی `limit=1` از همان API درخواست می‌کند. داده یا cursor ساختگی برنگردانده می‌شود.
- موفقیت واقعی clipboard و خواندن متن خام؛ رد شدن write و پیام شکست بدون موفقیت کاذب؛ متن کد در همهٔ حالات قابل انتخاب می‌ماند.
- درخواست شبکهٔ درحال‌اجرا پس از clear و تغییر tab نمی‌تواند نتایج را بازگرداند. پیشنهادها guard توالی/نسخه/خودرو دارند و ارسال Enter فوری است.
- نصب کامل ۳۶٬۵۶۹ ردیف و ۱٬۱۰۳ chunk، لغو نخستین دریافت و ادامه، reload واقعی با شبکهٔ قطع‌شده و Service Worker/IndexedDB؛ جست‌وجو و خانوادهٔ آفلاین.
- لغو update در مرز chunk با نسخه‌های fixture و حفظ نسخهٔ قبلی؛ بررسی بدون تغییر انتخاب preset را پاک نمی‌کند. کمبود quota با override آزمایشی `navigator.storage.estimate` در Worker شبیه‌سازی شد؛ هیچ chunk یا نسخهٔ ناقص فعال نشد. این آزمون، پرکردن واقعی دیسک نیست.

## حفظ کاتالوگ

کاتالوگ تولید دوباره import نشد. verifier روی پایگاه موجود اجرا شد؛ آزمون migration منبع کامل را در پایگاه موقت خودش نیز وارد و تطبیق داد.

- SHA-256 فایل اصلی: `5223b7729f85e7657129cfbad7db83910c827e4ec4e6668e1919be9bebd05480`.
- هر هشت فیلد `part/models/tech/log/price/replacement/friendly/aliases` برابرند؛ hash تمام ردیف‌ها، metadata و پایگاه برابر؛ mismatch صفر؛ foreign key violation صفر؛ integrity برابر `ok`؛ اختلاف گردکردن صفر.
- ۳۶٬۵۶۹ ردیف، ۳۱٬۵۰۹ کد فنی، ۱۹۲٬۶۳۰ رابطهٔ خودرو، ۷۳۸ alias و جمع قیمت پایه `5416428982434` باقی‌اند.
- ترتیب match، suffix و قیمت از موتور قبلی می‌آید. تنها گروه‌بندی `variant` به قرارداد خواندن افزوده شد؛ گونه‌ها با اولین فرزندِ مرتب‌شده صفحه‌بندی می‌شوند. UI رتبه‌بندی جدا ندارد.

## اندازه و زمان

HTML/CSS/main-JS gzip: **19,801 بایت**؛ قبل **16,608 بایت**. افزایش بابت رابط، dialog، adapter و وضعیت‌هاست؛ زیر هدف ۴۰KiB و سقف معماری ۲۵۰KiB است. مجموعهٔ JS شامل Worker: 53,745 بایت gzip. نبود literal کاتالوگ، دادهٔ خصوصی و API در کش پوسته بررسی شده است.

زمان کلیک تا شمارش صحیح و کارت‌های محدود، میلی‌ثانیه؛ یک نخستین اجرا و پنج تکرار گرم با cache Worker:

| query | قبل، نخستین | بعد، نخستین | قبل، میانهٔ گرم | بعد، میانهٔ گرم |
|---|---|---|---|---|
| `0CF25BE-1500011BA` | 1223.28 | 827.54 | 57.47 | 48.14 |
| `گیربکس اتوماتیک` | 2325.78 | 1823.59 | 58.93 | 54.54 |

بعد: DOMContentLoaded برابر 39.23ms؛ آمادگی نخستین جست‌وجوی آنلاین 93.30ms؛ دریافت دستی کامل 17867.87ms؛ پنج شروع نصب‌شده 22.98–54.84ms و صفر دانلود مجدد chunk. قبل، نصب خودکار در 18434.73ms تمام شد؛ این با آمادگی آنلاینِ بدون نصبِ بعد هم‌معنی نیست.

این‌ها اندازه‌گیری کوتاه با هزینهٔ automation هستند؛ INP، benchmark آماری، تأیید بهبود عمومی سرعت یا زمان Android نیستند. نخستین جست‌وجوی نام در اجرای ثبت‌شدهٔ بعد حدود 1.82 ثانیه طول کشید. storage فعلی: 1,292,468,773 بایت برای کل origin آزمایشی؛ اندازهٔ IndexedDB با snapshot دریافت‌شده یکسان نیست.

## بازبینی نهایی با UI UX Designer

قابلیت واقعی پلاگین نصب‌شده، بستهٔ محلی skills نسخهٔ **1.1.0** است؛ MCP جداگانه‌ای برای ساخت/بازبینی UI UX Designer در دسترس نبود. روش‌های `ui-ux-designer`, `redesign-makeover`, `design-to-code`, `ux-audit-critique`, `design-system-builder`, `accessibility-audit` توسط Codex روی صفحهٔ واقعی و تصاویر اعمال شدند. این بازبینی، نظر یک طراح خارجی یا اجرای سرویس AIDesigner نیست.

## محدودیت‌های صریح

- Android واقعی، کیبورد واقعی، WebView اندروید، screen reader و بزرگ‌نمایی متن در همهٔ مرورگرها آزموده نشده‌اند. بزرگ‌نمایی آزمون، CSS zoom=2 است.
- در مرورگر داخلی Codex رابط جدید باز شده است؛ وضعیت «پوستهٔ آفلاین تأیید نشده» در صورت نبود تأیید SW حفظ می‌شود. تأیید offline relaunch بالا مربوط به Chrome آزمایشی است.
- آزمون crash اجباری وسط import، پرشدن واقعی دیسک، رقابت کامل چندتب و قطع شبکه در تمام مراحل هنوز انجام نشده است؛ quota شبیه‌سازی و لغو chunk با نسخهٔ قبلی انجام شده‌اند.
- نمونه‌های timing محدودند؛ جست‌وجوی گستردهٔ آفلاین ممکن است چند ثانیه طول بکشد. هیچ ادعای بهبود عمومی عملکرد، APK، انتشار عمومی یا آمادگی TLS/auth عملیاتی مطرح نیست.
- ZIP مورخ ۲۶ اکتبر یک snapshot تاریخی است و با این تغییرات بازنویسی نشده است.
