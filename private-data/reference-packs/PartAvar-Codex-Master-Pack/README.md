# PartAvar Codex Master Pack

This ZIP is an implementation handoff for converting the legacy PartsFinder project into the PartAvar web platform.

## Start here

Give Codex the whole ZIP and tell it to read and execute:

`00-MASTER-CODEX-EXECUTION-PROMPT.md`
